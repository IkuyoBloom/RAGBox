# 检索增强生成（RAG）技术综述

## 一、背景与动机

大语言模型（Large Language Model, LLM）在预训练阶段将海量语料压缩进参数，
因而具备强大的语言理解与生成能力。但这种「参数化记忆」存在三个固有缺陷：

1. **知识截止**：模型的参数在训练完成后即被冻结，无法感知之后发生的事件。
2. **幻觉（Hallucination）**：当被问及训练数据中罕见或缺失的内容时，
   模型倾向于生成流畅但事实错误的答案，且往往以同样自信的语气表达。
3. **缺乏溯源**：参数化知识无法指出答案的出处，使用者难以验证其真实性。

检索增强生成（Retrieval-Augmented Generation, RAG）正是为缓解上述问题提出的范式。
其核心思想是：**把「记忆」从模型参数中外置到可检索的知识库**，
在生成之前先检索相关内容，再让模型基于检索结果作答。

## 二、基本架构

一个典型的 RAG 系统包含两个阶段。

### 2.1 离线索引阶段

1. **文档解析**：从 PDF、Word、Markdown 等格式中抽取纯文本，
   并尽量保留页码、标题层级等结构信息。
2. **文本切分（Chunking）**：将长文档切分为长度受控的片段。
   切分粒度过大会引入噪声并挤占上下文窗口；过小则会割裂语义。
   常见做法是递归字符切分，并设置 10% 至 20% 的重叠以避免答案正好落在边界上。
3. **向量化（Embedding）**：用嵌入模型将每个片段编码为稠密向量。
4. **入库**：将向量与其元数据写入向量数据库，同时建立稀疏索引。

### 2.2 在线推理阶段

1. **查询理解**：对用户问题做改写、扩展或多轮指代消解。
2. **检索**：从知识库中召回与问题最相关的若干片段。
3. **重排（可选）**：用交叉编码器对召回结果精排。
4. **生成**：将片段作为上下文与问题一同送入大模型，要求其依据上下文作答。
5. **引用标注**：要求模型在答案中标注来源编号，实现可溯源性。

## 三、检索方法

### 3.1 稀疏检索

稀疏检索以 BM25 为代表。它基于词袋假设，根据词频（TF）与逆文档频率（IDF）
对文档打分，并引入文档长度归一化。BM25 的评分公式为：
对查询中的每个词项，计算其 IDF 与饱和化后的词频之积，再求和。

BM25 的优点是**精确匹配能力强、可解释、无需训练**，
对专有名词、型号、编号等字面量查询表现优异。
缺点是存在**词汇鸿沟**：用户问「优化算法」，而文档写的是「梯度下降」，
只要没有共同词项，BM25 就打不出分数。

### 3.2 稠密检索

稠密检索用神经网络把查询和文档映射到同一向量空间，
以向量相似度衡量语义相关性。其典型结构是双塔模型（Dual Encoder）：
查询塔与文档塔分别编码，文档向量可离线预计算。

稠密检索能跨越词汇鸿沟，但**对罕见实体和精确字面匹配不敏感**，
且召回结果的可解释性较差。

### 3.3 混合检索与融合

由于两种方法互补，实践中常将二者结合。融合策略主要有两类：

- **加权求和**：需要归一化分数并调节权重，换模型后往往需要重新调参。
- **倒数排名融合（Reciprocal Rank Fusion, RRF）**：只利用排名信息，
  对每个文档计算各召回列表上排名倒数之和作为最终得分。
  RRF 对分数尺度不敏感，鲁棒性强，是工业界的常用基线。

## 四、评估方法

RAG 系统的评估分为检索质量与生成质量两个层面。

### 4.1 检索指标

- **命中率（Hit Rate@K）**：前 K 个结果中是否包含至少一个相关片段。
- **召回率（Recall@K）**：检索到的相关片段占全部相关片段的比例。
- **平均倒数排名（MRR）**：首个相关片段排名的倒数，反映头部排序质量。
- **归一化折损累计增益（NDCG@K）**：考虑相关性等级与位置折损的排序指标。

### 4.2 生成指标

- **忠实度（Faithfulness）**：答案中的陈述是否都能由检索到的上下文支撑，
  是衡量幻觉程度的核心指标。
- **答案相关性（Answer Relevancy）**：答案是否切题。
- **上下文精确率与召回率**：检索结果中有多少真正被用到、有多少被遗漏。

由于人工标注成本高昂，实践中常借助大语言模型作为评判者（LLM-as-a-Judge），
或使用 RAGAS 等自动化评估框架。

## 五、局限与展望

当前 RAG 系统仍面临若干挑战：

1. **检索失败即全盘失败**：若检索阶段未召回关键信息，生成阶段无从补救。
2. **多跳推理薄弱**：需要串联多个片段才能回答的问题，单轮检索往往不足。
3. **长文档处理**：超长文档的切分策略与层级摘要仍是开放问题。
4. **评估可信度**：以模型评判模型存在偏置，需要更可靠的人工校验机制。

未来的改进方向包括：查询分解与多轮检索、图结构知识库、
以及检索器与生成器的联合端到端训练。
